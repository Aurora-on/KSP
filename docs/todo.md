- [ ] **确定着陆点和目标坐标系**：经纬高、轴向与手性、四元数顺序、角速度的轴和单位、高度零点（质心高度换算为接触净空）。用静止直立、单轴小转动、单轴短脉冲、竖直点火四类检查确认。

- [ ] **制作动力下降存档和初态库**：现有测试存档位于约 15 km 高度的轨道，不是下降场景。已创建带展开着陆腿的候选基础快照；初态生成器已完成位置/速度/姿态修正 smoke test；KSP 读档会把角速度归零，当前作为已知 KSP 特性保留，正式 bank 规模和留出验收仍待决定。

- [ ] **reset 验收**：重复读档后的状态偏差在容差内；记录存档名、哈希和容差。首轮 benchmark 显示命名存档约 5.7 s/次且重复性较好，当前内存 Debug reset 约 6.5 s/次且修正后约 25.9 s/次，暂不替换存档路径。
