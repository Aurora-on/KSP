# 物理模型与数值方法

模型面向 Mun 附近平坦地点的短时动力下降预训练。默认值是 pilot 配置，不是对某一 KSP 飞行器的测量结果。名义训练使用固定物理参数、随机初态；泛化测试才独立改变质量、惯量、推力或重力。

仓库版稳定窗口采用 [共享任务契约](../../docs/task-spec.md) 已确定的 5 s；此前本地独立版的 2 s 配置及证据作为历史结果保留。其他参数仍为模拟器 pilot 假设，不据此填写 KSP 配置中的 TBD；接入范围见 [仓库接入说明](REPOSITORY_INTEGRATION.md)。

## 自由飞行

状态为世界系位置 `p`、速度 `v`、机体系到世界系的单位四元数 `q`、机体系角速度 `ω`、主推进剂质量 `f`。质量 `m = m_dry + f`，对角主惯量矩阵 `I` 在一次 episode 内固定。`e_z=(0,0,1)`，油门 `u_0∈[0,1]`，RCS 控制 `u_i∈[-1,1]`。

```text
dp/dt = v
dv/dt = R(q) e_z T / (m_dry + f) - g e_z
dq/dt = 1/2 q ⊗ (0, ω)
dω/dt = I⁻¹ [τ - ω × (Iω)]
df/dt = -T / (Isp_main g0)

T = u_0 T_max，燃料耗尽后 T = 0
τ_i = u_i τ_max,i
g0 = 9.80665 m/s²
```

用四阶 Runge–Kutta 积分，默认物理子步 0.02 s，每步单位化四元数。主发动机在子步中途耗尽时，按实际可燃烧时间分成有推力和无推力两段；燃料不为负，也不把最后少量燃料当作整步推力。发动机没有启动延迟、最小油门或转向机构。

RCS 为纯力矩，按等效力臂 `l` 计算耗料：

```text
dm_RCS/dt = (|τ_x| + |τ_y| + |τ_z|) / (l Isp_RCS g0)
```

这个等效模型相当于各轴力矩独立，不模拟实际喷口布局、组合控制饱和或 RCS 平移。RCS 储量视为充足，累计耗量用于奖励和报告，不从动力学质量或惯量中扣除。空中主推进剂耗尽会中止任务并算失败；已经触地且受支撑的飞行器可以继续完成稳定窗口。

## 地面与安全判定

`z=0` 是等效接触平面，位置高度按接触净空定义。自由飞行子步发生穿越时用二分定位首次接触事件，并保留碰撞前速度、姿态和角速度。对于子步中下降速度变为上升速度的近地情况，还检查内部高度最小值，避免先穿地再回到地面上方而漏检。总触地速度、机体推力轴与世界竖直方向夹角、角速度模任一超阈值则判碰撞失败。

通过初次接触检查后进入 `stabilizing`，继续积分控制输入与接触动力学，经过持续稳定窗口才能成为 `safe_landing`。地面模型含法向约束、水平摩擦和角速度阻尼；不能把状态直接冻结并等待计时。窗口内点火或姿态控制仍会改变状态，因此“刚触地”不等于“安全着陆”。离地时稳定计时归零；重新触地会再检查触地条件并重新计时，同时保留首次与最近一次触地记录。

这是集总接触近似，没有真实支腿几何、质心高度导致的支撑多边形失稳、结构弹性、弹跳、逐部件碰撞或损伤模型。这里的无损伤由接触阈值近似，KSP 评估必须另检查实际部件损坏。稳定结果用于源域接口验证，不证明真实飞行器不会倾覆。

稳定窗口内仍按同一速度/倾角/角速度阈值检查当前状态：窗口内任一物理子步超限都判 `crash`，不是只在首次触地时检查一次。因此持续的姿态控制或点火必须把状态保持在阈值内，否则即使初触安全也不会得到 `safe_landing`。

## 默认值与初态

| 项目 | 默认值 |
| --- | --- |
| 重力、干质量、主推进剂容量 | 1.63 m/s²，1200 kg，600 kg |
| 主发动机最大推力、Isp | 9000 N，310 s |
| 主惯量 | `(1200,1200,800)` kg·m² |
| 三轴 RCS 最大力矩 | `(900,900,400)` N·m |
| RCS Isp、等效力臂 | 240 s，1.4 m |
| 控制步长、物理步长、最长 episode | 0.1 s，0.02 s，90 s |
| 触地总速度、倾角、角速度上限 | 2 m/s，10°，0.2 rad/s |
| 稳定窗口、目标半径 | 5 s，5 m |
| 地面摩擦系数、角阻尼率 | 0.8，8 s⁻¹ |

初始 `x,y` 各自均匀采样于 `[-30,30] m`，高度均匀采样于 `[80,120] m`；水平速度各自位于 `[-2,2] m/s`，竖直速度位于 `[-8,-3] m/s`。推力轴在最大倾角 12° 的圆锥内按立体角均匀采样，yaw 均匀采样，初始角速度在半径 0.05 rad/s 的球内均匀采样。主发动机初始满油。分布与范围可配置并随实验保存。

质量泛化扰动的定义是改变干质量，使满油初始湿质量为名义值的指定倍数；燃料容量、惯量、推力和重力保持不变。惯量、推力、重力分别整体乘指定比例。该隔离试验定义不等同于实船增减部件后的自然耦合变化。

## 奖励

逐步奖励由运行代价、实际耗料和一次终止项组成：

```text
r = -dt [0.02 + 0.01 ||p_xy|| + 0.005 ||v|| + 0.02 tilt_rad]
    -0.1 Δm_main -1.0 Δm_RCS + r_terminal

r_terminal = +100：安全着陆
             -100：碰撞
              -50：燃料耗尽、超时或越界
                0：尚未结束
```

系数全部可配置。耗料项按 kg 计算；持续项乘实际 `dt`。落点精度始终有连续惩罚，但安全定义不包含目标半径。奖励只是训练信号，正式结果应分别报告安全率、碰撞率、全试验安全且入靶率、安全着陆水平误差，以及成功样本主/RCS/总耗料，不能只比较总奖励或所有样本平均耗料。

## 验证与适用限制

测试用自由落体解析解、变质量火箭方程、提前燃尽冲量、单轴力矩、无外力矩角动量/动能守恒检查物理实现，并检查坐标、单位四元数、可复现 reset/checkpoint、首次接触及稳定窗口、失败原因和 Gymnasium 契约。脚本控制器演示验证完整调用链；其成功率仅适用于对应配置和初态清单。

仓库保留 [验证摘要](validation-summary.json)、[着陆动画](assets/landing.gif) 和 [轨迹图](assets/trajectory.png)。完整复现方法见 [验收说明](VALIDATION.md)；`examples/reproduce_acceptance.py` 生成的原始评估、轨迹和机器记录只保存在本地 `artifacts/`，`examples/build_validation_summary.py --check` 可在不重跑评估的情况下校验源码与初态清单哈希。

本实现不包含轨道动力学、地形坡度、环境观测噪声、延迟、空气阻力、燃料晃动或时变惯量。若 KSP 实船误差显著，应先实测并校准这些差异，再决定是否扩展模型或将其作为独立鲁棒性条件，避免无记录地改变名义实验。
