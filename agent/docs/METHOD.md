# 模拟器内 Mun 着陆的训练方法

M0 完成 Python 包安装与导入检查。世界模型、想象轨迹上的策略更新和训练循环分别在后续里程碑实现。当前没有已运行的训练配置，也没有可报告的模型超参数或训练结果。

## 训练侧默认约定

以下是 2026-11-24 为名义配置 `LanderEnv` 选定的试验起点，作用范围为模拟器内的世界模型和策略训练。

| 决定 | 后续实现采用的约定 |
| --- | --- |
| D1 算法 | 采用 Dreamer 式循环状态空间模型（RSSM）。世界模型从真实模拟器转移学习，actor 和 critic 在模型想象的轨迹上更新。 |
| D2 回合结束 | 安全着陆、坠毁、燃料耗尽、超时和越界均停止价值自举。保留环境的两个原始结束标志，训练时取 `is_terminal = terminated or truncated`。超时和越界在本任务中都计为失败。 |
| D3 策略输入 | 使用原生 14 维观测及其历史。质量、惯量和 `info` 诊断字段不进入模型或策略。 |
| D4 预处理 | 将机体到世界旋转矩阵的前两列编码为 6 维姿态。位置、速度、角速度分别除以 100 m、10 m/s、0.5 rad/s，主燃料除以配置中的燃料容量，得到 16 维特征。 |
| D5 预填充 | 用脚本控制器加动作噪声采集演示回合，并加入少量随机策略回合。所有预填充转移都计入环境步数。 |
| D6 规模与预算 | 正式训练从 `base` 档起步，模型规模、每环境步的梯度更新次数和环境步数按试跑结果调整。 |

后续实现将逐项记录采用的 DreamerV3 默认值、为向量观测与连续动作所作的调整，以及实际使用的训练手段。实现参考 [DreamerV3 论文](https://arxiv.org/abs/2301.04104) 和[作者代码](https://github.com/danijar/dreamerv3)。
